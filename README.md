# Aigle d'Or — Backend

Ce dossier contient le serveur Node.js pour l'envoi d'emails.

## Installation

```bash
cd backend
npm install
```

## Configuration

1. Copier `.env` et renseigner vos identifiants SMTP
2. Pour Gmail : créer un mot de passe d'application sur https://myaccount.google.com/apppasswords

## Lancement

```bash
npm run dev
```

Le serveur démarre sur http://localhost:3000
